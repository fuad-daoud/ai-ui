# ai-ui v0.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build ai-ui v0.1.0: tokens, layered CSS, a Go adapter (asset handler and `html/template` partials), a React adapter, and the tests that keep them in step. Rollout step 1 of the spec.

**Architecture:** Plain CSS is the product. Sources live in `css/`, and `cmd/build` concatenates them into `dist/ui.css` inside `@layer ui.*`. The Go package `ui` (module root) embeds `dist/ui.css` and `js/theme.js`, serves them, and adds `ui.*` partials to an app's template set. `react/` ships TSX source that renders byte-for-byte the same markup. Parity fixtures in `testdata/parity/` are rendered by both sides and compared through two canonicalisers (Go and TypeScript) that are pinned by shared vectors.

**Tech Stack:** Go 1.25+ (`html/template`, `embed`, `net/http`, `golang.org/x/net/html` in tests only), CSS (cascade layers, `light-dark()`, oklch), React 19 + TypeScript (strict), vitest + jsdom + parse5, Tailwind v4 CLI (one test), Playwright + axe-core (gallery).

**Spec:** `docs/superpowers/specs/2026-11-03-shared-ui-design.md`

## Global Constraints

- Go module `github.com/fuad-daoud/ai-ui`, `go 1.25` in go.mod, package name `ui` at the module root. The only non-stdlib Go dependency is `golang.org/x/net`, imported only by `internal/canon` (test support).
- Go commands (`go test`, `go run`, `go vet`) run on the laptop.
- Node commands (`npm ci`, `npx vitest`, `npx tsc`, `npx @tailwindcss/cli`, `npx playwright`) run on the server: prefix them with `dev run` from `/home/fuad/projects/ai-ui`. `npm install -D …` may run locally and must be followed by `dev run npm ci`. The server is a one-way mirror (laptop → server): files created there do not come back unless you copy them (Task 14 shows how).
- Every library CSS rule ends up inside `@layer ui.reset`, `ui.base`, `ui.components` or `ui.utilities`. Source files under `css/` contain **no** `@layer` wrapper (the build adds it) and **no** `!important`.
- Naming: library tokens are unprefixed (`--ink`). Component knobs are `--ui-<component>-<property>` and default to tokens. The library never defines or reads `--app-*`. Classes are `.ui-<component>` and `.ui-<component>-<part>`.
- Variants and sizes are `data-variant` / `data-size` with enumerated values. A default value is never written as an attribute, and an unknown value renders the default (spec §6). State comes only from native HTML and ARIA (`:disabled`, `[aria-invalid="true"]`, `[aria-disabled="true"]`, `[open]`, `:checked`). No state classes.
- Every colour token in `css/tokens.css` is oklch and written as `light-dark(<light>, <dark>)`.
- Browser target: evergreen, Baseline 2025.
- After **any** change under `css/`, run `go run ./cmd/build` and commit `dist/ui.css` in the same commit. `TestDistIsFresh` fails otherwise.
- Go partials call only `ui_*` helpers, never `dict` or `href` (those are for app templates).
- React components render exactly their golden markup, append `className` after the library class on the root, and spread the remaining props (including `ref`) onto the root, or onto the form control for `Field` and `Check`.

```go
// Package color parses the colour syntaxes css/tokens.css uses and computes
// WCAG 2 contrast. It exists for the contrast test (spec §8.3).
package color

import (
	"errors"
	"fmt"
	"math"
	"strconv"
	"strings"
)

// RGB is a colour in linear-light sRGB, each channel clamped to [0, 1].
type RGB struct{ R, G, B float64 }

// Parse accepts "#rrggbb" and "oklch(L% C H)" with an optional " / alpha",
// which is ignored. Anything else is an error.
func Parse(s string) (RGB, error) {
	s = strings.TrimSpace(s)
	switch {
	case strings.HasPrefix(s, "#"):
		return parseHex(s)
	case strings.HasPrefix(s, "oklch(") && strings.HasSuffix(s, ")"):
		return parseOKLCH(strings.TrimSuffix(strings.TrimPrefix(s, "oklch("), ")"))
	}
	return RGB{}, fmt.Errorf("color: unsupported syntax %q", s)
}

func parseHex(s string) (RGB, error) {
	h := strings.TrimPrefix(s, "#")
	if len(h) != 6 {
		return RGB{}, fmt.Errorf("color: %q is not #rrggbb", s)
	}
	v, err := strconv.ParseUint(h, 16, 32)
	if err != nil {
		return RGB{}, fmt.Errorf("color: %q: %w", s, err)
	}
	ch := func(shift uint) float64 { return toLinear(float64((v>>shift)&0xff) / 255) }
	return RGB{ch(16), ch(8), ch(0)}, nil
}

func toLinear(c float64) float64 {
	if c <= 0.04045 {
		return c / 12.92
	}
	return math.Pow((c+0.055)/1.055, 2.4)
}

func parseOKLCH(body string) (RGB, error) {
	if i := strings.Index(body, "/"); i >= 0 {
		body = body[:i]
	}
	f := strings.Fields(body)
	if len(f) != 3 || !strings.HasSuffix(f[0], "%") {
		return RGB{}, fmt.Errorf("color: oklch(%s) wants \"L%% C H\"", body)
	}
	l, errL := strconv.ParseFloat(strings.TrimSuffix(f[0], "%"), 64)
	c, errC := strconv.ParseFloat(f[1], 64)
	h, errH := strconv.ParseFloat(f[2], 64)
	if err := errors.Join(errL, errC, errH); err != nil {
		return RGB{}, fmt.Errorf("color: oklch(%s): %w", body, err)
	}
	return fromOKLCH(l/100, c, h), nil
}

// fromOKLCH converts via Oklab to linear sRGB (Björn Ottosson's matrices),
// clamping out-of-gamut channels the way a browser's gamut mapping roughly does.
func fromOKLCH(L, C, H float64) RGB {
	a := C * math.Cos(H*math.Pi/180)
	b := C * math.Sin(H*math.Pi/180)
	l := cube(L + 0.3963377774*a + 0.2158037573*b)
	m := cube(L - 0.1055613458*a - 0.0638541728*b)
	s := cube(L - 0.0894841775*a - 1.2914855480*b)
	return RGB{
		clamp(4.0767416621*l - 3.3077115913*m + 0.2309699292*s),
		clamp(-1.2684380046*l + 2.6097574011*m - 0.3413193965*s),
		clamp(-0.0041960863*l - 0.7034186147*m + 1.7076147010*s),
	}
}

func cube(x float64) float64  { return x * x * x }
func clamp(x float64) float64 { return math.Min(1, math.Max(0, x)) }

// Luminance is the WCAG relative luminance of c.
func (c RGB) Luminance() float64 { return 0.2126*c.R + 0.7152*c.G + 0.0722*c.B }

// Contrast is the WCAG 2 contrast ratio between a and b, in [1, 21].
func Contrast(a, b RGB) float64 {
	la, lb := a.Luminance(), b.Luminance()
	if la < lb {
		la, lb = lb, la
	}
	return (la + 0.05) / (lb + 0.05)
}
```

```go
package ui_test

import (
	"fmt"
	"maps"
	"os"
	"regexp"
	"strings"
	"testing"

	"github.com/fuad-daoud/ai-ui/internal/color"
)

var (
	commentRE = regexp.MustCompile(`(?s)/\*.*?\*/`)
	blockRE   = regexp.MustCompile(`(?s):root(\[data-palette="([a-z0-9-]+)"\])?\s*\{(.*?)\}`)
	declRE    = regexp.MustCompile(`--([a-z0-9-]+)\s*:\s*([^;]+);`)
)

// palettes parses css/tokens.css into palette → token → [light, dark].
// "blue" is :root alone; every other palette is :root overlaid with its block.
// Blocks such as :root[data-theme="dark"] carry no tokens and are skipped.
func palettes(t *testing.T) map[string]map[string][2]string {
	t.Helper()
	src, err := os.ReadFile("css/tokens.css")
	if err != nil {
		t.Fatal(err)
	}
	clean := commentRE.ReplaceAllString(string(src), "")
	base := map[string][2]string{}
	overlays := map[string]map[string][2]string{}
	for _, m := range blockRE.FindAllStringSubmatch(clean, -1) {
		target := base
		if name := m[2]; name != "" {
			if overlays[name] == nil {
				overlays[name] = map[string][2]string{}
			}
			target = overlays[name]
		}
		for _, d := range declRE.FindAllStringSubmatch(m[3], -1) {
			v, err := lightDark(strings.TrimSpace(d[2]))
			if err != nil {
				t.Fatalf("--%s: %v", d[1], err)
			}
			target[d[1]] = v
		}
	}
	out := map[string]map[string][2]string{"blue": base}
	for name, o := range overlays {
		p := maps.Clone(base)
		maps.Copy(p, o)
		out[name] = p
	}
	return out
}

// lightDark splits "light-dark(A, B)" at its top-level comma. Any other value
// applies to both modes.
func lightDark(v string) ([2]string, error) {
	if !strings.HasPrefix(v, "light-dark(") {
		return [2]string{v, v}, nil
	}
	if !strings.HasSuffix(v, ")") {
		return [2]string{}, fmt.Errorf("unclosed light-dark: %q", v)
	}
	body := v[len("light-dark(") : len(v)-1]
	depth := 0
	for i, r := range body {
		switch r {
		case '(':
			depth++
		case ')':
			depth--
		case ',':
			if depth == 0 {
				return [2]string{strings.TrimSpace(body[:i]), strings.TrimSpace(body[i+1:])}, nil
			}
		}
	}
	return [2]string{}, fmt.Errorf("light-dark without a top-level comma: %q", v)
}

func TestLightDarkSplit(t *testing.T) {
	got, err := lightDark("light-dark(oklch(21% 0.03 262 / 0.12), oklch(0% 0 0 / 0.5))")

		t.Fatal(err)
	}
	want := [2]string{"oklch(21% 0.03 262 / 0.12)", "oklch(0% 0 0 / 0.5)"}
	if got != want {
		t.Errorf("got %q, want %q", got, want)
	}
	if _, err := lightDark("light-dark(oklch(1% 0 0))"); err == nil {

	}
}
```

```go
// Package build concatenates the css/ sources into dist/ui.css, wrapping each
// group in its cascade layer (spec §4.1). Sources contain no @layer of their own.
package build

import (
	"bytes"
	"fmt"
	"io/fs"
	"sort"
	"strings"
)

// Layers is the order every library rule lives in.
var Layers = []string{"ui.reset", "ui.base", "ui.components", "ui.utilities"}

// CSS returns the content of dist/ui.css built from fsys (the repository root).
func CSS(fsys fs.FS) ([]byte, error) {
	comps, err := fs.Glob(fsys, "css/components/*.css")
	if err != nil {
		return nil, fmt.Errorf("build: %w", err)
	}
	sort.Strings(comps)
	groups := [][]string{
		{"css/reset.css"},
		{"css/tokens.css", "css/base.css"},
		comps,
		{"css/utilities.css"},
	}
	var b bytes.Buffer
	b.WriteString("/* ai-ui: generated by `go run ./cmd/build` from css/. Do not edit. */\n")
	fmt.Fprintf(&b, "@layer %s;\n", strings.Join(Layers, ", "))
	for i, files := range groups {
		if len(files) == 0 {
			continue
		}
		fmt.Fprintf(&b, "\n@layer %s {\n", Layers[i])
		for _, f := range files {
			src, err := fs.ReadFile(fsys, f)
			if err != nil {
				return nil, fmt.Errorf("build: %w", err)
			}
			fmt.Fprintf(&b, "/* %s */\n", f)
			b.Write(bytes.TrimRight(src, "\n"))
			b.WriteString("\n")
		}
		b.WriteString("}\n")
	}
	return b.Bytes(), nil
}
```

`js/theme.js`:
```js
/* ai-ui theme.js: load it blocking in <head>, before the stylesheet:
     <script src="{{href "theme.js"}}"></script>
   It applies the visitor's stored theme and palette before first paint and
   persists new choices. Until the visitor chooses, the server's own
   data-theme / data-palette on <html> stay untouched.

   API:    window.aiui.theme.get()   -> { theme: "light"|"dark"|"system", palette: string }
           window.aiui.theme.set({ theme, palette })   null clears a choice
   Markup: <button data-ui-set-theme="dark">   <button data-ui-set-palette="mono">
           an empty value clears that choice */
(function () {
  "use strict";
  var KEY = "ai-ui:theme";
  var THEMES = ["light", "dark", "system"];
  var PALETTE = /^[a-z0-9-]{1,32}$/;
  var root = document.documentElement;
  var server = { theme: root.getAttribute("data-theme"), palette: root.getAttribute("data-palette") };
  var choice = clean(read());

  function read() {
    try {
      var v = JSON.parse(window.localStorage.getItem(KEY) || "{}");
      return v && typeof v === "object" ? v : {};
    } catch (e) {
      return {};
    }
  }

  function write() {
    try {
      window.localStorage.setItem(KEY, JSON.stringify(choice));
    } catch (e) {
      /* storage is blocked: the choice still applies to this page */
    }
  }

  function validTheme(v) {
    return THEMES.indexOf(v) >= 0;
  }

  function validPalette(v) {
    return typeof v === "string" && PALETTE.test(v);
  }

  function clean(v) {
    var c = {};
    if (validTheme(v.theme)) c.theme = v.theme;
    if (validPalette(v.palette)) c.palette = v.palette;
    return c;
  }

  function setAttr(name, value) {
    if (value) root.setAttribute(name, value);
    else root.removeAttribute(name);
  }

  function apply() {
    var theme = choice.theme ? (choice.theme === "system" ? null : choice.theme) : server.theme;
    setAttr("data-theme", theme);
    setAttr("data-palette", choice.palette || server.palette);
  }

  function get() {
    return {
      theme: choice.theme || server.theme || "system",
      palette: choice.palette || server.palette || "blue"
    };
  }

  function set(patch) {
    if (!patch || typeof patch !== "object") return get();
    if (patch.theme === null) delete choice.theme;
    else if (validTheme(patch.theme)) choice.theme = patch.theme;
    if (patch.palette === null) delete choice.palette;
    else if (validPalette(patch.palette)) choice.palette = patch.palette;
    apply();
    write();
    return get();
  }

  apply();

  document.addEventListener("click", function (e) {
    var t = e.target;
    var el = t && t.closest ? t.closest("[data-ui-set-theme],[data-ui-set-palette]") : null;
    if (!el) return;
    var patch = {};
    if (el.hasAttribute("data-ui-set-theme")) patch.theme = el.getAttribute("data-ui-set-theme") || null;
    if (el.hasAttribute("data-ui-set-palette")) patch.palette = el.getAttribute("data-ui-set-palette") || null;
    set(patch);
  });

  window.aiui = window.aiui || {};
  window.aiui.theme = { get: get, set: set };
})();
```

```go
package ui

import (
	"bytes"
	"crypto/sha256"
	"embed"
	"encoding/hex"
	"fmt"
	"io/fs"
	"net/http"
	"path"
	"strings"
	"time"
)

//go:embed dist/ui.css js/theme.js
var raw embed.FS

// Prefix is the path Handler expects to be mounted under:
//
//	mux.Handle(ui.Prefix, http.StripPrefix(ui.Prefix, ui.Handler()))
const Prefix = "/_ui/"

// published maps each public asset name to its file in the repository.
var published = map[string]string{
	"ui.css":   "dist/ui.css",
	"theme.js": "js/theme.js",
}

var contentTypes = map[string]string{
	".css": "text/css; charset=utf-8",
	".js":  "text/javascript; charset=utf-8",
}

type asset struct {
	body  []byte
	hash  string
	ctype string
}

var assets = loadAssets()

func loadAssets() map[string]asset {
	m := make(map[string]asset, len(published))
	for name, file := range published {
		b, err := raw.ReadFile(file)
		if err != nil {
			panic("ui: embedded asset missing: " + file)
		}
		sum := sha256.Sum256(b)
		m[name] = asset{body: b, hash: hex.EncodeToString(sum[:])[:12], ctype: contentTypes[path.Ext(name)]}
	}
	return m
}

// Assets holds the published files, opened by their public names
// ("ui.css", "theme.js").
var Assets fs.FS = publicFS{}

type publicFS struct{}

func (publicFS) Open(name string) (fs.File, error) {
	file, ok := published[name]
	if !ok {
		return nil, &fs.PathError{Op: "open", Path: name, Err: fs.ErrNotExist}
	}
	return raw.Open(file)
}

// Href returns the URL of a published asset with its content hash, such as
// "/_ui/ui.css?v=3f2a9c0b1d4e". It panics on an unknown name, so a typo
// fails at the first render.
func Href(name string) string {
	a, ok := assets[name]
	if !ok {
		panic(fmt.Sprintf("ui: unknown asset %q (published: ui.css, theme.js)", name))
	}
	return Prefix + name + "?v=" + a.hash
}

// Handler serves the published assets. A request whose ?v= matches the
// asset's hash is cached for a year as immutable. Any other request gets
// Cache-Control: no-cache, so a link written without Href is never pinned
// to a stale copy.
func Handler() http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if r.Method != http.MethodGet && r.Method != http.MethodHead {
			w.Header().Set("Allow", "GET, HEAD")
			http.Error(w, "method not allowed", http.StatusMethodNotAllowed)
			return
		}
		name := strings.TrimPrefix(r.URL.Path, "/")
		a, ok := assets[name]
		if !ok {
			http.NotFound(w, r)
			return
		}
		h := w.Header()
		h.Set("Content-Type", a.ctype)
		h.Set("X-Content-Type-Options", "nosniff")
		h.Set("ETag", `"`+a.hash+`"`)
		if r.URL.Query().Get("v") == a.hash {
			h.Set("Cache-Control", "public, max-age=31536000, immutable")
		} else {
			h.Set("Cache-Control", "no-cache")
		}
		http.ServeContent(w, r, name, time.Time{}, bytes.NewReader(a.body))
	})
}
```

```go
// Package canon turns an HTML fragment into one canonical string, so markup
// from the Go partials and the React components can be compared (spec §8.1).
// test/canon.ts mirrors these rules; testdata/canon/cases.json pins both.
// Change them together.
package canon

import (
	"sort"
	"strings"

	"golang.org/x/net/html"
	"golang.org/x/net/html/atom"
)

var void = map[string]bool{
	"area": true, "base": true, "br": true, "col": true, "embed": true, "hr": true, "img": true,
	"input": true, "link": true, "meta": true, "source": true, "track": true, "wbr": true,
}

var (
	textEscaper = strings.NewReplacer("&", "&amp;", "<", "&lt;", ">", "&gt;")
	attrEscaper = strings.NewReplacer("&", "&amp;", "<", "&lt;", ">", "&gt;", `"`, "&quot;")
)

// HTML parses s as a fragment in <body> context and serialises it canonically.
func HTML(s string) (string, error) {
	ctx := &html.Node{Type: html.ElementNode, Data: "body", DataAtom: atom.Body}
	nodes, err := html.ParseFragment(strings.NewReader(s), ctx)
	if err != nil {
		return "", err
	}
	var b strings.Builder
	for _, n := range nodes {
		write(&b, n)
	}
	return b.String(), nil
}

// words collapses runs of HTML whitespace (space, tab, LF, CR, FF) and trims.
func words(s string) string {
	return strings.Join(strings.FieldsFunc(s, func(r rune) bool {
		return r == ' ' || r == '\t' || r == '\n' || r == '\r' || r == '\f'
	}), " ")
}

func write(b *strings.Builder, n *html.Node) {
	switch n.Type {
	case html.TextNode:
		if t := words(n.Data); t != "" {
			b.WriteString(textEscaper.Replace(t))
		}
	case html.ElementNode:
		b.WriteString("<" + n.Data)
		attrs := append([]html.Attribute(nil), n.Attr...)
		sort.Slice(attrs, func(i, j int) bool { return attrs[i].Key < attrs[j].Key })
		for _, a := range attrs {
			v := a.Val
			if a.Key == "class" {
				v = words(v)
			}
			b.WriteString(" " + a.Key)
			if v != "" {
				b.WriteString(`="` + attrEscaper.Replace(v) + `"`)
			}
		}
		b.WriteString(">")
		for c := n.FirstChild; c != nil; c = c.NextSibling {
			write(b, c)
		}
		if !void[n.Data] {
			b.WriteString("</" + n.Data + ">")
		}
	}
}
```

```ts
// Canonical HTML for the parity tests: the TypeScript twin of internal/canon.
// testdata/canon/cases.json pins both. Change them together.
import { parse, parseFragment } from "parse5";
import type { DefaultTreeAdapterMap } from "parse5";

type ChildNode = DefaultTreeAdapterMap["childNode"];
type Element = DefaultTreeAdapterMap["element"];
type TextNode = DefaultTreeAdapterMap["textNode"];
type Template = DefaultTreeAdapterMap["template"];

const VOID = new Set(["area", "base", "br", "col", "embed", "hr", "img", "input", "link", "meta", "source", "track", "wbr"]);
const WS = /[ \t\n\r\f]+/;

const body: Element = (() => {
  const doc = parse("<!doctype html><html><head></head><body></body></html>");
  const html = doc.childNodes.find((n) => n.nodeName === "html") as Element;
  return html.childNodes.find((n) => n.nodeName === "body") as Element;
})();

const words = (s: string) => s.split(WS).filter(Boolean).join(" ");
const escText = (s: string) => s.replace(/&/g, "&amp;").replace(/</g, "&lt;").replace(/>/g, "&gt;");
const escAttr = (s: string) => escText(s).replace(/"/g, "&quot;");

export function canon(src: string): string {
  return parseFragment(body, src).childNodes.map(write).join("");
}

function write(n: ChildNode): string {
  if (n.nodeName === "#text") {
    const t = words((n as TextNode).value);
    return t ? escText(t) : "";
  }
  if (!("tagName" in n)) return "";
  const el = n as Element;
  const attrs = [...el.attrs]
    .sort((a, b) => (a.name < b.name ? -1 : a.name > b.name ? 1 : 0))
    .map(({ name, value }) => {
      const v = name === "class" ? words(value) : value;
      return v ? ` ${name}="${escAttr(v)}"` : ` ${name}`;
    })
    .join("");
  const kids = el.tagName === "template" ? (el as Template).content.childNodes : el.childNodes;
  const open = `<${el.tagName}${attrs}>`;
  return VOID.has(el.tagName) ? open : `${open}${kids.map(write).join("")}</${el.tagName}>`;
}
```

```go
func parityCases(t *testing.T) (map[string]parityCase, []string) {

		t.Fatal(err)
	}
	if len(files) == 0 {
		t.Fatal("no fixtures in testdata/parity")
	}
	cases := make(map[string]parityCase, len(files))
	var keys []string
	for _, f := range files {
		b, err := os.ReadFile(f)
		if err != nil {
			t.Fatal(err)
		}
		var c parityCase
		dec := json.NewDecoder(bytes.NewReader(b))
		dec.DisallowUnknownFields()
		if err := dec.Decode(&c); err != nil {
			t.Fatalf("%s: %v", f, err)
		}
```

```go
//go:embed templates/*.tmpl
var partials embed.FS

// Option is one <option> of a select field.
type Option struct{ Value, Label string }

// Parse adds the ui.* partials and their helpers to t and returns t.
//
// App templates get dict (build a map for a partial's arguments) and href
// (ui.Href). The partials call only the ui_* helpers, so an app that later
// redefines dict or href does not break them.
func Parse(t *template.Template) (*template.Template, error) {
	if t == nil {
		return nil, errors.New("ui: Parse needs a template")
	}
	return t.Funcs(funcs).ParseFS(partials, "templates/*.tmpl")
}

var funcs = template.FuncMap{
	"dict":        dict,
	"href":        Href,
	"ui_str":      str,
	"ui_or":       or,
	"ui_variant":  variant,
	"ui_required": required,
}

func dict(kv ...any) (map[string]any, error) {
	if len(kv)%2 != 0 {
		return nil, fmt.Errorf("dict: odd number of arguments (%d)", len(kv))
	}
	m := make(map[string]any, len(kv)/2)
	for i := 0; i < len(kv); i += 2 {
		k, ok := kv[i].(string)
		if !ok {
			return nil, fmt.Errorf("dict: key %d is %T, want string", i/2, kv[i])
		}
		m[k] = kv[i+1]
	}
	return m, nil
}

// str renders a template value as text. A missing map key (nil) is "".
func str(v any) string {
	switch x := v.(type) {
	case nil:
		return ""
	case string:
		return x
	case fmt.Stringer:
		return x.String()
	default:
		return fmt.Sprint(x)
	}
}

func or(v any, fallback string) string {
	if s := str(v); s != "" {
		return s
	}
	return fallback
}

// variant returns v if it is one of allowed, else "". The caller then omits
// the attribute and the component's default applies (spec §6).
func variant(v any, allowed ...string) string {
	s := str(v)
	for _, a := range allowed {
		if s == a {
			return s
		}
	}
	return ""
}

func required(component, key string, v any) (string, error) {
	if s := str(v); s != "" {
		return s, nil
	}
	return "", fmt.Errorf("%s: %s is required", component, key)
}
```

```ts
export function cx(...parts: (string | false | null | undefined)[]): string {
  return parts.filter(Boolean).join(" ");
}

// pick returns value if it is one of allowed, else undefined. React then
// omits the attribute and the component's default applies (spec §6).
export function pick<T extends string>(value: unknown, allowed: readonly T[]): T | undefined {
  return (allowed as readonly unknown[]).includes(value) ? (value as T) : undefined;
}

export function present(v: unknown): boolean {
  return v !== undefined && v !== null && v !== false && v !== "";
}

// invoker returns the lowercase command / commandfor attributes of an
// invoker button (spec §4.3), omitting the empty ones.
export function invoker(command?: string, commandFor?: string): Record<string, string> {
  const a: Record<string, string> = {};
  if (command) a.command = command;
  if (commandFor) a.commandfor = commandFor;
  return a;
}
```

```tsx
import type { ComponentPropsWithRef } from "react";
import { cx, invoker, pick } from "./util";

export type ButtonVariant = "primary" | "secondary" | "ghost" | "danger";
export type ButtonSize = "sm" | "md" | "lg";

const VARIANTS = ["secondary", "ghost", "danger"] as const;
const SIZES = ["sm", "lg"] as const;
const TYPES = ["submit", "reset"] as const;

export type ButtonProps = Omit<ComponentPropsWithRef<"button">, "type"> & {
  variant?: ButtonVariant;
  size?: ButtonSize;
  type?: "button" | "submit" | "reset";
  command?: string;
  commandFor?: string;
};

export function Button({ variant, size, type, command, commandFor, className, ...rest }: ButtonProps) {
  return (
    <button
      {...rest}
      {...invoker(command, commandFor)}
      className={cx("ui-btn", className)}
      type={pick(type, TYPES) ?? "button"}
      data-variant={pick(variant, VARIANTS)}
      data-size={pick(size, SIZES)}
    />
  );
}

export type ButtonLinkProps = ComponentPropsWithRef<"a"> & {
  variant?: ButtonVariant;
  size?: ButtonSize;
  disabled?: boolean;
};

export function ButtonLink({ variant, size, disabled, href, className, ...rest }: ButtonLinkProps) {
  return (
    <a
      {...rest}
      className={cx("ui-btn", className)}
      href={disabled ? undefined : href}
      aria-disabled={disabled ? "true" : undefined}
      data-variant={pick(variant, VARIANTS)}
      data-size={pick(size, SIZES)}
    />
  );
}
```

```go
// fieldID is ID if set, else Name. A field with neither cannot be labelled.
func fieldID(component string, id, name any) (string, error) {
	if s := str(id); s != "" {
		return s, nil
	}
	if s := str(name); s != "" {
		return s, nil
	}
	return "", fmt.Errorf("%s: needs ID or Name", component)
}

// describedBy lists the hint and error ids that are present, in that order.
func describedBy(id string, hint, err any) string {
	var ids []string
	if str(hint) != "" {
		ids = append(ids, id+"-hint")
	}
	if str(err) != "" {
		ids = append(ids, id+"-error")
	}
	return strings.Join(ids, " ")
}

// selected reports whether an option is the field's value. A field with no
// Value (nil) selects nothing.
func selected(value, option any) bool {
	return value != nil && str(value) == str(option)
}
```

```tsx
import type { ComponentPropsWithRef, ReactNode } from "react";
import { cx, pick, present } from "./util";

const INPUT_TYPES = ["email", "password", "number", "search", "tel", "url", "date"] as const;
export type InputType = "text" | (typeof INPUT_TYPES)[number];
export type FieldOption = { value: string; label: string };

type FieldBase = {
  label: ReactNode;
  name?: string;
  id?: string;
  hint?: ReactNode;
  error?: ReactNode;
  className?: string;
};
type Own = keyof FieldBase | "control";

export type InputFieldProps = FieldBase & { control?: "input"; type?: InputType } & Omit<ComponentPropsWithRef<"input">, Own | "type">;
export type TextareaFieldProps = FieldBase & { control: "textarea" } & Omit<ComponentPropsWithRef<"textarea">, Own>;
export type SelectFieldProps = FieldBase & { control: "select"; options: readonly FieldOption[] } & Omit<ComponentPropsWithRef<"select">, Own>;
export type FieldProps = InputFieldProps | TextareaFieldProps | SelectFieldProps;

type Wiring = { id: string; name?: string; "aria-describedby"?: string; "aria-invalid"?: "true" };

export function Field(props: FieldProps) {
  const { label, name, id: idProp, hint, error, className, ...controlProps } = props;
  const id = idProp || name;
  if (!id) throw new Error("ui.field: needs ID or Name");
  const hasHint = present(hint);
  const hasError = present(error);
  const describedBy = [hasHint ? `${id}-hint` : "", hasError ? `${id}-error` : ""].filter(Boolean).join(" ");
  const wiring: Wiring = {
    id,
    name,
    "aria-describedby": describedBy || undefined,
    "aria-invalid": hasError ? "true" : undefined,
  };
  return (
    <div className={cx("ui-field", className)}>
      <label className="ui-field-label" htmlFor={id}>{label}</label>
      {control(controlProps, wiring)}
      {hasHint && <p className="ui-field-hint" id={`${id}-hint`}>{hint}</p>}
      {hasError && <p className="ui-field-error" id={`${id}-error`}>{error}</p>}
    </div>
  );
}

type ControlProps = {
  control?: string;
  type?: string;
  options?: readonly FieldOption[];
  defaultValue?: string | number | readonly string[];
};

// blank drops an empty defaultValue, so an empty input renders no value
// attribute, matching the Go partial.
const blank = (v: ControlProps["defaultValue"]) => (v === "" ? undefined : v);

function control(props: object, wiring: Wiring): ReactNode {
  const { control: kind, type, options, defaultValue, ...rest } = props as ControlProps;
  if (kind === "textarea") {
    return <textarea {...(rest as ComponentPropsWithRef<"textarea">)} {...wiring} className="ui-textarea" defaultValue={blank(defaultValue)} />;
  }
  if (kind === "select") {
    return (
      <select {...(rest as ComponentPropsWithRef<"select">)} {...wiring} className="ui-select" defaultValue={defaultValue}>
        {(options ?? []).map((o) => (
          <option key={o.value} value={o.value}>{o.label}</option>
        ))}
      </select>
    );
  }
  return <input {...(rest as ComponentPropsWithRef<"input">)} {...wiring} className="ui-input" type={pick(type, INPUT_TYPES) ?? "text"} defaultValue={blank(defaultValue)} />;
}
```


```css
/* ai-ui for Tailwind v4. In the app stylesheet, import in this order:
     @import "ai-ui/theme.css";
     @import "tailwindcss";
     @import "ai-ui/ui.css";
   The first import fixes the layer order, so Tailwind utilities beat the
   ui components (class="ui-btn rounded-none" works) and the components beat
   Tailwind's base. Fonts, radii and text sizes are not remapped: ai-ui
   defines --font-sans, --radius-md, --text-sm and friends itself, in a later
   layer than Tailwind's theme, so Tailwind's font-sans, rounded-md and
   text-sm utilities already resolve to the ai-ui values. */
@layer theme, base, ui, components, utilities;
```

```go
// Command gallery serves every ai-ui v0.1 component in each palette and mode,
// for screenshots and accessibility checks (spec §8.2):
//
//	go run ./gallery -addr 127.0.0.1:4317
package main

import (
	"bytes"
	_ "embed"
	"flag"
	"html/template"
	"log"
	"net/http"
	"slices"

	ui "github.com/fuad-daoud/ai-ui"
)

//go:embed page.html
var pageSrc string

var (
	palettes   = []string{"blue", "mono"}
	modes      = []string{"light", "dark"}
	currencies = []ui.Option{{Value: "usd", Label: "US dollar"}, {Value: "jod", Label: "Jordanian dinar"}, {Value: "eur", Label: "Euro"}}
)

type link struct {
	Href, Label string
	Current     bool
}

type page struct {
	Palette, Mode string
	Dialog        bool
	Links         []link
	Currencies    []ui.Option
}

func main() {
	addr := flag.String("addr", "127.0.0.1:4317", "listen address")
	flag.Parse()
	h, err := newHandler()
	if err != nil {
		log.Fatal(err)
	}
	log.Printf("gallery on http://%s/", *addr)
	log.Fatal(http.ListenAndServe(*addr, h))
}

func newHandler() (http.Handler, error) {
	set, err := ui.Parse(template.New("gallery"))
	if err != nil {
		return nil, err
	}
	if _, err := set.New("page").Parse(pageSrc); err != nil {
		return nil, err
	}
	mux := http.NewServeMux()
	mux.Handle(ui.Prefix, http.StripPrefix(ui.Prefix, ui.Handler()))
	mux.HandleFunc("GET /{$}", func(w http.ResponseWriter, r *http.Request) {
		http.Redirect(w, r, "/p/blue/light", http.StatusFound)
	})
	serve := func(dialog bool) http.HandlerFunc {
		return func(w http.ResponseWriter, r *http.Request) {
			p, m := r.PathValue("palette"), r.PathValue("mode")
			if !slices.Contains(palettes, p) || !slices.Contains(modes, m) {
				http.NotFound(w, r)
				return
			}
			var b bytes.Buffer
			data := page{Palette: p, Mode: m, Dialog: dialog, Links: links(p, m), Currencies: currencies}
			if err := set.ExecuteTemplate(&b, "page", data); err != nil {
				http.Error(w, err.Error(), http.StatusInternalServerError)
				return
			}
			w.Header().Set("Content-Type", "text/html; charset=utf-8")
			_, _ = b.WriteTo(w)
		}
	}
	mux.HandleFunc("GET /p/{palette}/{mode}", serve(false))
	mux.HandleFunc("GET /p/{palette}/{mode}/dialog", serve(true))
	return mux, nil
}

func links(palette, mode string) []link {
	var out []link
	for _, p := range palettes {
		for _, m := range modes {
			out = append(out, link{Href: "/p/" + p + "/" + m, Label: p + " " + m, Current: p == palette && m == mode})
		}
	}
	return out
}
```

`DESIGN.md`:
````markdown
# ai-ui design contract

This file is the contract between ai-ui and the apps that use it. A change
that renames or removes anything named here is a breaking change (see
CHANGELOG.md and spec §9).

## Override model

Every library rule lives in a cascade layer:

```css
@layer ui.reset, ui.base, ui.components, ui.utilities;
```

Any unlayered rule in an app beats every library rule, with no `!important`.
You can override at three levels:

1. **Theme**: set tokens on `:root` in your app CSS: `:root { --primary: oklch(52% 0.2 150); }`.
   Use `light-dark(<light>, <dark>)` to cover both modes in one line.
2. **Component**: set a knob: `.ui-btn { --ui-btn-radius: 0; }`. A knob set on the
   root class also overrides the knob values the variants set, so target the default
   variant alone with `.ui-btn:not([data-variant])`.
3. **Anything else**: write a plain rule. An unlayered app rule also beats the
   library's state rules (`:hover`, `[aria-invalid]`) for the same property, so
   restate the states you need.

Tokens that belong to one app are named `--app-*`. The library never defines or reads them.

## Tokens

| Group | Tokens |
|---|---|
| Surfaces | `--paper` page, `--band` secondary strip, `--sheet` card/panel |
| Text | `--ink`, `--ink-2`, `--ink-3` |
| Lines | `--rule`, `--rule-soft`, `--rule-field` (input borders) |
| Action | `--primary`, `--on-primary`, `--primary-hover`, `--link`, `--focus`, `--accent` |
| Status | `--good`, `--good-bg`, `--warning`, `--warning-bg`, `--bad`, `--bad-bg` |
| Effects | `--mark-bg`, `--shadow`, `--scrim` |
| Type | `--font-sans`, `--font-display` (defaults to `--font-sans`), `--font-mono`, `--text-xs` … `--text-3xl` |
| Shape | `--space-1` … `--space-8`, `--radius-sm`, `--radius-md`, `--radius-lg` |
| Motion | `--dur` (0ms under reduced motion), `--ease` |

The contrast pairs `go test` enforces in every palette and mode: `ink`, `ink-2` and `ink-3`
on `paper`, `band` and `sheet`; `on-primary` on `primary`, `primary-hover` and `bad`;
`link` on `paper`, `band` and `sheet`; each status colour on its `-bg`, all at 4.5:1 or more;
and `rule-field` on `sheet` at 3:1 or more.

## Modes and palettes

- The mode follows the OS. `<html data-theme="light|dark">` forces one.
- `<html data-palette="mono">` selects the neutral palette. `blue` is the default and needs no attribute.
- An app adds a palette in its own CSS: `:root[data-palette="whiteboard"] { --paper: …; }`.
- `theme.js` (load it blocking in `<head>`) applies and persists the visitor's choice.
  Use `<button data-ui-set-theme="dark">`, `data-ui-set-theme="system"` or
  `<button data-ui-set-palette="mono">`; an empty value clears the choice. From script,
  use `window.aiui.theme.get()` and `.set({ theme, palette })`. Until the visitor
  chooses, the server's own `data-theme` / `data-palette` stay untouched.

## Components

Variants and sizes are `data-variant` / `data-size`. A default is never written as an
attribute, and an unknown value renders the default. State comes from native HTML and
ARIA only.

### Button: `.ui-btn`

Knobs: `--ui-btn-bg`, `--ui-btn-fg`, `--ui-btn-border`, `--ui-btn-bg-hover`, `--ui-btn-fg-hover`, `--ui-btn-radius`, `--ui-btn-height`, `--ui-btn-pad`, `--ui-btn-font-size`.

| | Go | React |
|---|---|---|
| Button | `{{template "ui.button" (dict "Label" "Save" "Variant" "secondary" "Size" "sm" "Type" "submit")}}` | `<Button variant="secondary" size="sm" type="submit">Save</Button>` |
| Link | `{{template "ui.button" (dict "Label" "Docs" "Href" "/docs")}}` | `<ButtonLink href="/docs">Docs</ButtonLink>` |
| Dialog opener | `(dict "Label" "Open" "Command" "show-modal" "CommandFor" "confirm")` | `<Button command="show-modal" commandFor="confirm">Open</Button>` |

Variants: `primary` (default), `secondary`, `ghost`, `danger`. Sizes: `sm`, `md` (default), `lg`.
`Disabled` on a link drops `href` and sets `aria-disabled="true"`. Labels are text.

```html
<button class="ui-btn" type="button" data-variant="secondary" data-size="sm">Save</button>
```

### Field: `.ui-field`

Knobs: `--ui-field-gap`; on controls, `--ui-input-bg`, `--ui-input-fg`, `--ui-input-border`, `--ui-input-radius`, `--ui-input-height`.

Go args: `Label` (required), `ID` or `Name` (at least one), `Control` (`textarea`, `select`; default input), `Type` (`email`, `password`, `number`, `search`, `tel`, `url`, `date`; default `text`), `Value`, `Placeholder`, `Autocomplete`, `Rows`, `Options` (`[]ui.Option`), `Hint`, `Error`, `Required`, `Disabled`.
React: `<Field label name id control type options defaultValue hint error … />`. Every other prop, including `ref`, goes to the control.

```html
<div class="ui-field">
  <label class="ui-field-label" for="email">Email</label>
  <input class="ui-input" id="email" name="email" type="email" aria-describedby="email-hint email-error" aria-invalid="true" required>
  <p class="ui-field-hint" id="email-hint">We never share it.</p>
  <p class="ui-field-error" id="email-error">That address bounced.</p>
</div>
```

Lay fields side by side with `<div class="ui-form-row">`.

### Check: `.ui-check`

Knobs: `--ui-check-size`, `--ui-check-accent`.
Go: `{{template "ui.check" (dict "Label" "Monthly" "Name" "period" "Value" "m" "Type" "radio" "Checked" true)}}`. React: `<Check label="Monthly" name="period" value="m" type="radio" defaultChecked />`.

```html
<label class="ui-check"><input class="ui-check-input" type="radio" name="period" value="m" checked><span class="ui-check-label">Monthly</span></label>
```

### Pill: `.ui-pill`

Knobs: `--ui-pill-bg`, `--ui-pill-fg`, `--ui-pill-border`. Variants: neutral (default), `info`, `good`, `warning`, `bad`.
Go: `{{template "ui.pill" (dict "Label" "Paid" "Variant" "good")}}`. React: `<Pill variant="good">Paid</Pill>`.

### Dialog: `.ui-dialog`

Knobs: `--ui-dialog-width`, `--ui-dialog-bg`, `--ui-dialog-radius`, `--ui-dialog-pad`. It needs no JavaScript:
open it with a button carrying `command="show-modal" commandfor="<id>"`. React: `<Dialog id="confirm" title="Delete resume?">…</Dialog>`.
In Go, write this markup (it is pinned by `testdata/parity/dialog-basic.html`):

```html

  <header class="ui-dialog-head">
    <h2 class="ui-dialog-title" id="confirm-title">Delete resume?</h2>
    <button class="ui-dialog-x" type="button" command="close" commandfor="confirm" aria-label="Close">×</button>
  </header>
  <div class="ui-dialog-body">
    This cannot be undone.
    <div class="ui-dialog-actions">…buttons…</div>
  </div>
</dialog>
```

### Containers (plain markup in Go and React)

```html
<div class="ui-callout" data-variant="bad">          <!-- info (default), good, warning, bad -->
  <p class="ui-callout-title">Build failed</p>
  <p>The gate found 3 unsupported claims.</p>
</div>

<div class="ui-table-wrap">
  <table class="ui-table">
    <caption>October spending</caption>
    <thead><tr><th scope="col">Category</th><th scope="col" class="ui-num">Amount</th></tr></thead>
    <tbody><tr><td>Groceries</td><td class="ui-num">212.40</td></tr></tbody>
  </table>
</div>

<details class="ui-disclosure" name="faq">
  <summary class="ui-disclosure-summary">Can I export it?</summary>
  <div class="ui-disclosure-body"><p>Yes, as CSV or JSON.</p></div>
</details>

<section class="ui-card">…</section>
```

Knobs: `--ui-callout-bg`, `--ui-callout-fg`, `--ui-callout-accent`; `--ui-table-pad-y`, `--ui-table-pad-x`; `--ui-card-pad`, `--ui-card-radius`.

### Utilities

`.ui-muted` (ink-3), `.ui-mono`, `.ui-num` (tabular, end-aligned), `.ui-vh` (visually hidden),
`.ui-stack` (column, gap `--ui-stack-gap`), `.ui-cluster` (wrapping row, gap `--ui-cluster-gap`).
````
