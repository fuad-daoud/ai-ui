# ai-ui site, first version: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static site with a home page ("The pile"), release notes and an `AGENTS.md`, ready to publish on GitHub Pages.

**Architecture:** A nested Go module in `site/` renders embedded templates with the real `ui.*` partials and writes plain HTML to `site/out/`. Every internal path is relative, so the output works under `/ai-ui/`. A GitHub Actions workflow publishes it on pushes to `main`.

**Tech Stack:** Go 1.25, `html/template`, goldmark, plain CSS on `dist/ui.css`, a little vanilla JS, Playwright with axe.

**Spec:** `docs/superpowers/specs/2026-11-07-site-design.md`

## Global Constraints

- No token, class, partial or React component changes, no version bump and no tag.
- Site copy never states how many components there are.
- The site doesn't claim agents produce better UI.
- Own classes never use the `ui-` prefix.
- No request to any host except GitHub. The font is self-hosted.
- Every internal link and asset path is relative.
- The whole site is dark, set with `data-theme="dark"`. There is no toggle and `theme.js` isn't loaded.
- The fall ends within five seconds.
- Nothing is pushed, merged or changed in repository settings without Fuad's go-ahead.

## Review Focus

- **The clipboard is refused:** the button says so and points at the visible prompt. Owned by Task 4.
- **Scripts are off:** the page still reads, the prompt is visible, and buttons that can't work are hidden. Owned by Task 4.
- **Widths between phone and desktop,** including either side of the layout switch: no control is covered or cut off. Owned by Task 4.
- **A missing or broken `CHANGELOG.md` or `package.json`:** the build fails and writes nothing, so CI can't publish an empty site. Owned by Task 2.
- **Raw HTML in `CHANGELOG.md`:** it's dropped, never passed through to the page. Owned by Task 2.

````markdown file=AGENTS.md
## Rules

- Use a library component before writing your own.
- Use only names in the contract. Never invent a `ui-*` class, and don't give your own classes that
  prefix.
- Don't write a default as an attribute. An unknown value renders the default, so a typo fails
  quietly: check names against the contract.
- Theme through tokens and knobs in the app's own unlayered CSS. Name tokens that belong to the app
  `--app-*`.
- Never edit the library's files, and never use `!important` to beat it. An unlayered rule already
  wins.

## A project that already has CSS

`ui.css` changes every element its rules touch. Before adding it to an existing app, read "Adopting
ai-ui in an app that has its own CSS" in the contract, and consider `ui-scoped.css` for a page whose
other content must stay as it is.
````

```go file=site/main_test.go
// built builds the real site once, from the real repository.
func built(t *testing.T) string {
	t.Helper()
	builtOnce.Do(func() {
		builtDir, builtErr = os.MkdirTemp("", "ai-ui-site")
		if builtErr == nil {
			builtErr = build(builtDir, "..")
		}
	})
	if builtErr != nil {
		t.Fatal(builtErr)
	}
	return builtDir
}

func parse(t *testing.T, path string) *html.Node {
	t.Helper()
	f, err := os.Open(path)
	if err != nil {
		t.Fatal(err)
	}
	defer f.Close()
	n, err := html.Parse(f)
	if err != nil {
		t.Fatal(err)
	}
	return n
}

func walk(n *html.Node, visit func(*html.Node)) {
	visit(n)
	for c := n.FirstChild; c != nil; c = c.NextSibling {
		walk(c, visit)
	}
}

func attr(n *html.Node, name string) string {
	for _, a := range n.Attr {
		if a.Key == name {
			return a.Val
		}
	}
	return ""
}

func text(n *html.Node) string {
	var b strings.Builder
	walk(n, func(c *html.Node) {
		if c.Type == html.TextNode {
			b.WriteString(c.Data)
			b.WriteString(" ")
		}
	})
	return b.String()
}

func TestLinksResolveAndStayOnGitHub(t *testing.T) {
	out := built(t)
	for _, p := range pages {
		walk(parse(t, filepath.Join(out, p)), func(n *html.Node) {
			if n.Type != html.ElementNode {
				return
			}
			ref := attr(n, "href")
			if ref == "" {
				ref = attr(n, "src")
			}
			switch {
			case ref == "", strings.HasPrefix(ref, "#"), strings.HasPrefix(ref, "data:"):
			case strings.HasPrefix(ref, "/"):
				t.Errorf("%s: %q isn't relative", p, ref)
			case strings.Contains(ref, "://"):
				if !strings.HasPrefix(ref, "https://github.com/fuad-daoud/ai-ui") && !strings.HasPrefix(ref, "https://raw.githubusercontent.com/fuad-daoud/ai-ui/") {
					t.Errorf("%s: %q leaves GitHub", p, ref)
				}
			default:
				target := filepath.Join(out, filepath.Dir(p), ref)
				if info, err := os.Stat(target); err == nil && info.IsDir() {
					target = filepath.Join(target, "index.html")
				}
				if _, err := os.Stat(target); err != nil {
					t.Errorf("%s: %q doesn't resolve", p, ref)
				}
			}
		})
	}

}

			}
		})
	}
}
```

```go file=site/main.go
// Command site builds the ai-ui website into a directory of static files:
//
//	go run . -out out
//	go run . -out out -serve 127.0.0.1:4318
//
// Every internal link is relative, so the output works under any path.
package main

import (
	"bytes"
	"embed"
	"encoding/json"
	"errors"
	"flag"
	"fmt"
	"html/template"
	"io/fs"
	"log"
	"net/http"
	"os"
	"path/filepath"
	"strings"

	ui "github.com/fuad-daoud/ai-ui"
	"github.com/yuin/goldmark"
	"github.com/yuin/goldmark/parser"
)

//go:embed templates/*.html
var templates embed.FS

//go:embed assets
var assets embed.FS

const (
	repoURL     = "https://github.com/fuad-daoud/ai-ui"
	contractURL = repoURL + "/blob/main/DESIGN.md"
	readmeURL   = repoURL + "/blob/main/README.md"
	agentsURL   = "https://raw.githubusercontent.com/fuad-daoud/ai-ui/main/AGENTS.md"
	prompt      = "Use ai-ui for this project's UI. Read " + agentsURL + " first and follow it."
)

// page is what every template renders from.
type page struct {
	Title, Description string
	Root               string // relative path back to the site root, "./" or "../"
	Version            string
	Prompt             string
	RepoURL            string
	ContractURL        string
	ReadmeURL          string
	Changelog          template.HTML
	Currencies         []ui.Option
}

func main() {
	out := flag.String("out", "out", "directory to write the site to")
	repo := flag.String("repo", "..", "the repository root")
	serve := flag.String("serve", "", "after building, serve the site under /ai-ui/ on this address")
	flag.Parse()
	if err := build(*out, *repo); err != nil {
		log.Fatal(err)
	}
	if *serve == "" {
		return
	}
	mux := http.NewServeMux()
	mux.Handle("/ai-ui/", http.StripPrefix("/ai-ui/", http.FileServer(http.Dir(*out))))
	mux.Handle("/{$}", http.RedirectHandler("/ai-ui/", http.StatusFound))
	log.Printf("site on http://%s/ai-ui/", *serve)
	log.Fatal(http.ListenAndServe(*serve, mux))
}

// build renders everything before it writes anything, so a broken source
// leaves no output behind for CI to publish.
func build(out, repo string) error {
	version, err := readVersion(repo)
	if err != nil {
		return err
	}
	changelog, err := renderChangelog(repo)
	if err != nil {
		return err
	}
	set, err := ui.Parse(template.New("site"))
	if err != nil {
		return err
	}
	if set, err = set.ParseFS(templates, "templates/*.html"); err != nil {
		return err
	}
	base := page{
		Version:     version,
		Prompt:      prompt,
		RepoURL:     repoURL,
		ContractURL: contractURL,
		ReadmeURL:   readmeURL,
	}

	files := map[string][]byte{}

	home := base
	home.Title = "ai-ui: the UI kit your agent can read"
	home.Description = "A small pile of real, working UI components, written down in one contract your coding agent can read."
	home.Root = "./"
	home.Currencies = []ui.Option{{Value: "usd", Label: "US dollar"}, {Value: "eur", Label: "Euro"}}
	if files["index.html"], err = render(set, "home.html", home); err != nil {
		return err
	}

	releases := base
	releases.Title = "Release notes: ai-ui"
	releases.Description = "What changed in each release of ai-ui."
	releases.Root = "../"
	releases.Changelog = changelog
	if files["releases/index.html"], err = render(set, "releases.html", releases); err != nil {
		return err
	}

	if files["assets/ui.css"], err = fs.ReadFile(ui.Assets, "ui.css"); err != nil {
		return err
	}
	err = fs.WalkDir(assets, "assets", func(p string, d fs.DirEntry, err error) error {
		if err != nil || d.IsDir() {
			return err
		}
		files[p], err = fs.ReadFile(assets, p)
		return err
	})
	if err != nil {
		return err
	}

	for name, body := range files {
		path := filepath.Join(out, filepath.FromSlash(name))
		if err := os.MkdirAll(filepath.Dir(path), 0o755); err != nil {
			return err
		}
		if err := os.WriteFile(path, body, 0o644); err != nil {
			return err
		}
	}
	return nil
}

func render(set *template.Template, name string, data page) ([]byte, error) {
	var b bytes.Buffer
	if err := set.ExecuteTemplate(&b, name, data); err != nil {
		return nil, fmt.Errorf("render %s: %w", name, err)
	}
	return b.Bytes(), nil
}

func readVersion(repo string) (string, error) {
	raw, err := os.ReadFile(filepath.Join(repo, "package.json"))
	if err != nil {
		return "", err
	}
	var pkg struct{ Version string }
	if err := json.Unmarshal(raw, &pkg); err != nil {
		return "", fmt.Errorf("package.json: %w", err)
	}
	if pkg.Version == "" {
		return "", errors.New("package.json has no version")
	}
	return pkg.Version, nil
}

// renderChangelog leaves goldmark's default in place: raw HTML in the Markdown
// is dropped, not passed through.
func renderChangelog(repo string) (template.HTML, error) {
	raw, err := os.ReadFile(filepath.Join(repo, "CHANGELOG.md"))
	if err != nil {
		return "", err
	}
	if strings.TrimSpace(string(raw)) == "" {
		return "", errors.New("CHANGELOG.md is empty")
	}
	var b bytes.Buffer
	md := goldmark.New(goldmark.WithParserOptions(parser.WithAutoHeadingID()))
	if err := md.Convert(raw, &b); err != nil {
		return "", fmt.Errorf("CHANGELOG.md: %w", err)
	}
	return template.HTML(b.String()), nil
}
```

```js file=site/assets/site.js
// Copy buttons and Drop it again. Both start hidden, so a page without
// scripts doesn't offer buttons that can't work.
(function () {
  "use strict";

  document.querySelectorAll("[data-copy]").forEach(function (button) {
    var label = button.textContent;
    var timer;
    function say(text) {
      button.textContent = text;
      clearTimeout(timer);
      timer = setTimeout(function () { button.textContent = label; }, 2500);
    }
    button.hidden = false;
    button.addEventListener("click", function () {
      var text = document.getElementById("prompt").textContent.trim();
      var fail = function () { say("Couldn't copy, select the text below"); };
      if (!navigator.clipboard) { fail(); return; }
      navigator.clipboard.writeText(text).then(function () { say("Copied"); }, fail);
    });
  });

  var pile = document.getElementById("pile");
  var drop = document.getElementById("drop");
  if (pile && drop) {
    drop.hidden = false;
    // Two identical animations, so swapping them restarts the fall without
    // re-creating the components or clearing anything typed into them.
    drop.addEventListener("click", function () {
      pile.classList.toggle("run-a");
      pile.classList.toggle("run-b");
    });
  }
})();
```

```yaml file=.github/workflows/pages.yml
name: pages
on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version-file: site/go.mod
      - run: go test ./...
        working-directory: site
      - run: go run . -out out
        working-directory: site
      - uses: actions/upload-pages-artifact@v5
        with:
          path: site/out
  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deploy.outputs.page_url }}
    steps:
      - id: deploy
        uses: actions/deploy-pages@v5
```
