# ai-ui v0.3.2: two fixes found in career

Date: 2026-11-12
Status: approved by Fuad, 2026-11-12 ("keep going do them all in the order that you recommend, go
with the recs", after v0.3.2 was recommended first). That approval covers merge, tag and site deploy.

## 1. Purpose

Moving career onto v0.3.1 found two gaps. Career carries a rule for each in `workbench.css`; this
release moves both into the library so career can drop them.

| Gap | Seen in career | Career's rule today |
|---|---|---|
| A dialog title can't shrink: a long unbroken word (an email address) keeps the title its full width, so the head overflows and the dialog scrolls sideways | admin's Delete dialog made the page 657px wide on a 360px phone | `.wb .ui-dialog-title { min-width: 0; overflow-wrap: anywhere; }` |
| `data-head="quiet"` quiets only the head row; a row header in the body (`<th scope="row">`) keeps the default `--band` fill | grey bars behind the account page's labels on a phone | `.wb .ui-table[data-head="quiet"] tbody th { background: transparent; color: var(--ink-3); font-size: 12px; }` |

## 2. Changes

1. `.ui-dialog-title` gets `min-inline-size: 0` (it is a flex item in `.ui-dialog-head`) and
   `overflow-wrap: anywhere` (the reset's `break-word` doesn't lower a flex item's min-content).
2. `.ui-table[data-head="quiet"] :where(tbody th)`: no fill, `--ui-table-head-fg`,
   `--ui-table-head-size`. Not `--ui-table-head-case`: a row header is a label, not a column name.
   `:where()` keeps the specificity under the row hover rule, so a quiet row still tints on hover.

Both are look changes, not breaking: no name is added, renamed or removed.

## 3. Tests

- On a 360px phone, a dialog whose title is a long email address keeps the title inside the dialog
  and the × after it, and the dialog doesn't scroll sideways. Without change 1 the title starts at
  x = -197.
- A quiet table's row header has no fill, `--ink-3`, 12px, no case change; a default table's row
  header keeps `--band`; hovering the row still tints it. Without change 2 the fill test fails;
  without `:where()` the hover test fails.

Gallery baselines don't change (checked on the trial: 18 gallery tests pass against v0.3.1's).

## 4. After the release

Career pins v0.3.2 and deletes its two rules; its page captures must not move.
