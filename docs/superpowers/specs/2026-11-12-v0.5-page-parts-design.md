(2026-11-11 sizing, money B4, B6, B8–B11, B13, B14, B17; career B5, B11–B15). After v0.4 took the
overlays, these are what's left before money can drop its own components and `compat.css`.

| Current row | ledger | claims |

## 2. Non-goals

- **No Go partials or React components.** Every part is plain markup in both stacks, like tables
  and cards. Go and React apps write the same classes.
- **No tabs or sidebar nav, toasts, tooltips, lightbox, chart legend.** Each is one app's, or a
  layout.
- **No tick on the meter, no stacked splits.** Those are money's charts.
- **No dashed filter chip.** Money keeps that one look as an override.

## 3. Parts

Three new files, so the site's "every component" rule stays one class per file:

- `page.css`: `.ui-page-head` (`.ui-page-title`, `.ui-page-sub`, `.ui-page-aside`), `.ui-eyebrow`,
  `.ui-section-head` (`.ui-section-index`, `.ui-section-title`, `.ui-section-count`,
  `.ui-section-aside`), `.ui-stats` (`.ui-stat`, `.ui-stat-value`, `.ui-stat-note`) and `.ui-empty`
  (`.ui-empty-title`).
- `chip.css`: `.ui-chips`, `.ui-chip`, `.ui-badge`, `.ui-segmented`, `.ui-segment`, `.ui-avatar`.
- `meter.css`: `.ui-meter` on a native `<progress>`.

And in `table.css`: the current row.

| Part | Decision |
|---|---|
| Page head | Flex row, wrapping: the first child holds eyebrow, title and sub; `.ui-page-aside` sits at the end on the title's last line. A `--rule` under it. Title `clamp(1.75rem, 1.2rem + 1.6vw, 2.375rem)`: 28px on a phone to 38px wide, the range both apps use. |
| Eyebrow | `--text-xs`, 600, `0.08em`, uppercase, `--ink-3`. Career's (13px, `--link`, no case) is two knobs. |
| Section head | Baseline-aligned flex row; index in `--primary`, 700; count `--ink-3`; aside pushed to the end. A `--rule` under it (career sets `--ui-section-rule: var(--rule-soft)`). |
| Stats | A `<dl>` grid, `repeat(auto-fit, minmax(min(9rem, 100%), 1fr))`, 1px gaps on a `--rule-soft` ground give hairlines without end rules. Label small and grey (`--ui-stat-label-case` for money's uppercase), value 1.75rem 650 tabular, note small. `data-variant` on a tile colours its value; on a note, the note; `muted` greys a zero. `data-frame="none"` for a strip without a frame. |
| Empty state | Dashed `--rule` frame, centred, `--ink-2`; `data-frame="none"` flush and start-aligned (money's). |
| Chip | 28px (40px coarse), `--rule` border, `--sheet`, `--ink-2`; current by `aria-current` (links) or `aria-pressed="true"` (toggles): `--primary` border on `--mark-bg`, 600. |
| Badge | A count pill: `--band`, `--ink-2`, `--text-xs` 600 tabular. Knobs for money's no-fill tab badge. |
| Segmented | `--rule-field` frame, `--rule-soft` dividers; chosen segment `--primary` with `--on-primary`; `aria-disabled` greys one on `--band` and keeps it focusable (money's Year). |
| Avatar | Initial on a `--mark-bg` circle (money's home); inside a square button it fills the button with no circle (both apps' account button: Go `Shape "square"` with `Icon` = the avatar markup). |
| Meter | Native `<progress>`: a progressbar for free. Track `--band`, fill `--primary`, 0.5rem, round. No value: a segment slides (`@keyframes ui-meter-slide`), and stands still under reduced motion. `data-variant` colours the fill. |
| Current row | `tr[aria-current]` (or `aria-selected="true"` in a grid) keeps `--ui-table-selected` (`--mark-bg`), under the pointer too. |

## 4. Tests

- Browser (`e2e/parts.spec.ts`): page head aside placement and wrap on a phone, title size; eyebrow
  look; section head aside; equal tiles, tabular values and variant colours, frameless strip;
  current and pressed chips; segment states; avatar shapes; meter role, size and slide, still
  under reduced motion; empty state frames; the current row under the pointer; finger sizes on a
  coarse pointer.
- The scoped-sheet comparison freezes animations first, so the indeterminate meter can't make the
  two snapshots differ.
- Gallery: a Page parts section and a current table row; 16 baselines change. axe runs on every
  gallery page.
- Site: Page parts, Chips and Meter sections with demos, and the three in the home pile. The site's
  "every component" test now reads hyphenated class names (`.ui-page-head`).
